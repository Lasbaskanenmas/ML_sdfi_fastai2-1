# Spatial CV matrix - config manifest

72 training configs in `train/`, 72 inference configs in `infer/`. 24 cells = 4 models x 3 channels x {weighted, unweighted}, x 3 folds.

Trainer per model: resnet34 + segformer-b1 -> `segformer_train.py`; convnext/swin upernet -> `train.py`.
Unweighted jobs carry a `_unw` suffix; they are identical to the weighted cell except class_weights are off (still cross_entropy).
